# Changelog

## Version 1.1.0

### Added
- **XP Costs**: Applying Soul Speed to harnesses via anvil now costs experience points, just like vanilla enchanting
- **Anvil Fix**: Fixed issue where enchanted harnesses couldn't be taken out of the anvil after combining

### Improved
- Better compatibility with Paper 1.21+ anvil system
- More reliable anvil interaction when adding Soul Speed to harnesses

---

## Version 1.0.0

### Initial Release
- Soul Speed enchantment support for Happy Ghast harnesses
- Automatic speed boost based on Soul Speed level (40% per level)
- Support for all 16 harness color variants
- Event-based performance optimization
